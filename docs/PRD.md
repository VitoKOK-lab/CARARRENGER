# 機構排班系統 — 產品規格書(PRD)

適用機構:線東大眾護理之家
文件版本:對應目前系統實作狀態(含自動排班第一版)

---

## 1. 一句話說清楚做什麼

讓機構能用一套系統管理護理／行政／照服三職務的月班表,支援多人共用即時同步、權限分級、班表健檢(勞基法對照)、以及針對護理人員的自動排班草稿產生。

---

## 2. 為什麼要做這個

- 原本用 Excel 排班,格式、公式、顏色標記都要人工維護,容易出錯、不同人版本不一致
- 護理人員排班規則複雜(9種班別代碼、輪調模組、休息間隔、例假規定),人工排班容易漏檢查,也難以證明「有沒有符合勞基法」
- 機構有多位管理者(老闆、主任、護理長)需要用不同權限操作或檢視同一份班表,原本各自拿著自己的 Excel 檔案,對不起來
- 每年12月要公告隔年休假規劃,也需要跟機構實際挪移後的版本比對

---

## 3. 使用者故事

### 故事1:管理者排班
> 身為主任
> 我想要在日曆介面上直接點格子輸入班別代碼、或是從 Excel 貼上整月班表
> 這樣我才能快速把班表建立起來,不用重新設計格式

**驗收標準:**
- 點擊儲存格可直接輸入班別代碼,支援自動完成建議清單
- 可用方向鍵在儲存格間移動,Ctrl+C/V/Z 可複製、貼上、復原
- 可從 Excel 整塊複製多人多天的資料,貼上後自動對應到正確的人員列與日期欄
- 護理人員頁面顯示9種內建班別代碼(Di/2Di/3Di/D8/E/E8/N/Dp/Ep)+ 休假/空班/預約休假/機構排定休假標記,行政與照服人員使用簡化的早/中/晚/休

### 故事2:護理長檢視班表
> 身為護理長
> 我只需要看護理職務的班表,不需要編輯權限
> 這樣主任跟老闆可以放心讓我看到最新班表,又不用擔心我誤改

**驗收標準:**
- 登入後只看得到自己有「檢視」或「編輯」權限的職務頁籤,其餘頁籤不顯示
- 只有檢視權限的職務,點擊儲存格會提示「僅有檢視權限」,無法進入編輯狀態
- 拖曳排序、快速登記休假等會修改資料的操作,同樣受權限限制

### 故事3:排班合規健檢
> 身為主任
> 我想要一鍵檢查目前班表有沒有違反勞基法或機構內部規則
> 這樣我才能在公告班表前先抓出問題,而不是等出事才發現

**驗收標準:**
- 健檢涵蓋:班別資格對應、休息間隔(11小時)、14天2例假、4週8天休假(4週變形工時)、每月加班時數上限(46小時)、每日最低人力、連續上班天數、每月休假天數、週末需求、特休天數需求達成率
- 每條規則可在後台設定「不可違反/建議盡量」、數字門檻、適用對象(全職+兼職 / 僅全職)、是否啟用
- 健檢結果依嚴重程度分色顯示(紅=不可違反、黃=建議調整),並附上後台「常用解決方案庫」對應的建議做法
- 每月休假天數門檻優先讀取「年度行事曆」中該月機構實際休假天數,沒有設定才退回固定參數

### 故事4:護理人員自動排班草稿
> 身為主任
> 我想要讓系統依照人員資格、輪調模組、人力需求自動排出一版草稿
> 這樣我不用從零開始排,只要在草稿基礎上微調

**驗收標準:**
- 只覆蓋空白儲存格,已手動填寫的格子一律保留不動
- 純白班同仁依「輪調起始月份＋起始班別」自動判斷本月應輪值 2Di / 3Di / 貼班,貼班同仁自動補上當天固定班同仁休假時的空缺
- 可上小夜/大夜的同仁,依每日人力需求與公平性(排最少的人優先)自動分配
- 排不出來的情況(找不到人選、輪調設定衝突)明確列出原因,不會硬塞不合適的人
- 草稿產生後自動接續執行一次健檢,結果一併呈現

### 故事5:年度基準與機構規則維護
> 身為主任
> 我想要把政府公告的年度行事曆跟機構挪移後的版本都建進系統
> 這樣每個月該休幾天就有依據,不用每次用嘴巴講

**驗收標準:**
- 後台可用 Excel 貼上方式建立「人事行政局公告版本」與「機構挪移後版本」兩張12個月表格
- 機構版本的「機構實休」天數會自動成為健檢「每月休假天數」規則的當月門檻
- 後台另可維護「機構常態規則」(每月第幾週星期幾的固定會議/事件)與「特殊日期註記」(單次性標記),兩者皆可設定顯示顏色,並顯示在班表下方對應日期

## 4. 系統邊界與已知限制(誠實列出)

| 項目 | 現況 |
|---|---|
| 帳號安全性 | 應用層級的帳號密碼,非銀行等級加密;資料為共用儲存,實際存取範圍取決於系統檔案/連結的散布範圍 |
| 登入狀態 | 僅保留在單次瀏覽期間,重新整理需要重新登入(無記住登入功能) |
| 健檢法規依據 | 已對照公開勞基法條文(§32、§34、§36)校正,但非律師出具的正式合規保證,建議搭配勞資顧問或當地勞動局複核 |
| 加班時數計算 | 概估值(以排定班別時數 - 基準工時推算),未涵蓋國定假日出勤加給、休息日加班級距等細節 |
| 自動排班演算法 | 逐步啟發式排法,非最佳化求解器;僅支援護理人員;公平性僅止於小夜/大夜次數平均 |
| 週末需求規則 | 目前僅實作 w1(六日至少休一)與 w5(六日都休),w2/w3/w4 尚未實作 |
| 列印/系統對話框 | 因執行環境限制,採用「開新分頁列印」與「畫面內二次確認」取代瀏覽器原生列印與彈窗功能 |

---

## 5. 怎麼知道成功了

- 主任/老闆可以完全取代 Excel,在系統內完成整月排班與公告前檢查
- 護理長登入後看不到編輯功能、也看不到其他職務資料
- 健檢報告抓到的問題,經人工複核後沒有明顯漏抓的違規情況
- 自動排班草稿產生後,平均只需要少量人工微調(而非整月重排)即可公告
