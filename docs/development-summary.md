# 線東大眾護理之家 機構排班系統 — 開發總結

最後更新:對話至今所有已完成項目彙整

---

## 一、專案背景

1. 建立公司 CIS 品牌識別系統(色票、字體、版面語言),存成獨立文件供後續所有工具套用
2. 依據 CIS 打造「機構排班系統」,支援護理人員(9種班別代碼)、行政人員、照顧服務員三種職務
3. 系統分成兩大畫面:**📅 班表檢視**(日常操作) 與 **⚙ 後台管理**(需密碼,資料維護)

---

## 二、班表檢視(日常操作畫面)

### 基本結構
- 品牌 Logo 置頂,三職務頁籤切換,月份導覽(整月日曆式,非單週)
- 表格風格仿 Excel:格線、標題列底色、姓名+代碼欄位固定(橫向捲動時不跑掉)

### 護理人員班別代碼(9種 + 延伸)
| 代碼 | 說明 |
|---|---|
| Di | 行政班 08:00-16:00,不卡現場 |
| 2Di / 3Di | 2樓／3樓白班現場 08:00-16:00 |
| 2D8 / 3D8 / D8 | 12小時白班支援(自動併入 2Di/3Di 人力統計) |
| E | 小夜班 16:00-24:00 |
| E8 | 12小時大夜支援(同時計入小夜與大夜人力) |
| N | 大夜班 24:00-08:00 |
| Dp / Ep | 兼職支援(白班/小夜),約3小時,限固定到班星期 |
| 休 | 一般休假 |
| / | 空班 |
| R1 | 預約休假(同仁申請)— 藍色 R |
| R2 | 機構排定休假 — 深綠色 R |
| R(單獨) | 從 Excel 貼上時自動視為休假,套用 R1 樣式 |

行政人員／照服人員維持簡化的「早／中／晚／休／R」。

### 操作功能
- **點格輸入**:點儲存格開放輸入,可打字或用下拉建議清單(datalist)
- **鍵盤導覽**:方向鍵在儲存格間移動並自動存檔
- **Ctrl+C／Ctrl+V／Ctrl+Z**:單格複製貼上、復原(內建防護,避免瀏覽器沙盒環境擋掉時失效)
- **整塊貼上**:可直接從 Excel 複製一整塊班表(多人×多天),貼到起始儲存格即自動展開填入
- **拖曳排序**:姓名前「⠿」圖示可拖曳調整人員列順序,方便比對
- **快速登記休假**:選人員＋類型(R1/R2)＋日期(逗號分隔)一次套用多天
- **本月特休天數需求登記**:記錄同仁申請天數(不綁日期,供人工排休參考)
- **本月休假總計欄**:每列最右自動加總該員休假天數
- **班次人數統計列**:2Di／3Di／小夜／大夜每日人力,低於門檻自動標紅
- **機構事件顯示**:表格最下方另起「日期列＋事件色塊列」,顯示常態會議/特殊日期(顏色可自訂,不影響上方班表版面)
- **匯出 Excel**:一鍵匯出目前職務+月份的完整班表(含代碼、統計列、休假總計;R1/R2 統一顯示為 R)
- **列印 A4 橫式**:開新分頁排版列印(避免內嵌環境阻擋列印動作)
- **🩺 排班健檢**:見下方說明

## 三、後台管理(密碼保護)

### 1. 人員資料庫
Excel 風格表格,可直接編輯既有資料、整塊貼上覆蓋。護理人員欄位包含:
姓名、代碼(供 ERP 匯入)、班別資格(白班/小夜/大夜可複選)、輪調模組(尚未指定/三個月輪調一次)、是否兼職＋固定到班星期、週末特殊需求(5種,含完整文字說明,非代碼)

### 2. 班別代碼維護
- 系統內建 9 大類代碼:可編輯說明文字,顏色與代碼本身固定(避免破壞既有視覺語言)
- 自訂班別代碼:可新增機構專屬代碼,自選顯示顏色,新增後自動出現在輸入建議清單

### 3. 排班規則設定
9 條可調整的規則(資格對應、休息間隔12hr、14天2例假、每日最低人力、連續上班上限、每月休假天數、週末需求、特休需求達成率),每條可設定:
- **類型**:不可違反 / 建議盡量
- **參數**:數字門檻
- **適用對象**:全職＋兼職 / 僅全職人員(例如每月休假天數已預設僅全職適用)
- **啟用**:開關

### 4. 常用解決方案庫
針對每種規則情境,可預先寫好慣用處理建議,健檢報告會自動帶出。

### 5. 年度行事曆
- **人事行政局公告版本**:12個月固定表格,可整塊貼上政府公告資料
- **機構挪移後版本**:同結構,國假調移與「機構挪移國定假日」可編輯
- 機構版「機構實休」數字會**自動成為健檢「每月休假天數」規則的動態門檻**,取代單一固定數字

### 6. 機構常態規則
每月固定第幾週星期幾發生的事(如雙週會、月務會議),可設定顏色,系統自動換算成當月實際日期並顯示在班表下方事件列。

### 7. 特殊日期註記
單次性日期標記(如評鑑日),同樣可設定顏色。

## 四、🩺 排班健檢(第二階段前置作業,已完成)

點擊「排班健檢」會依「排班規則設定」逐條檢查目前職務＋月份的班表,產生報告:
- 紅色卡片:不可違反(如休息不足12小時、當日某班次掛零人力)
- 黃色卡片:建議調整(如休假天數不足、週末需求未滿足)
- 每項附上「常用解決方案庫」中對應的建議做法

**目前限制(誠實告知)**:
- 休息間隔計算採固定時段模型,Dp/Ep 因時段不固定暫不納入此項檢查
- 週末需求目前只做 w1(六日至少休一)與 w5(六日都休)兩種,w2/w3/w4 邏輯較複雜尚未實作
- 這是「健檢」不是「自動修正」,只負責找問題、給建議,不會自動改班表

## 五、尚未開始:第二階段「自動草稿產生」

規劃方向已與你確認:
1. 用同一套「排班規則設定」反過來自動填格子,而非只檢查
2. 產生的是**草稿**,不保證零違規,需搭配健檢報告人工微調
3. 需要處理的複雜情境:純白班同仁的三個月輪調模組(2Di/3Di/貼班)、小夜班人力優先填補、特殊日(評鑑/巡診)人力例外規則等
